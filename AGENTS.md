# Agent instructions

This repository holds the public GitHub profile of the NDDev Standards organization. Every change
follows the owner's standards.

- Edit the introduction in `profile/README.md` and its cover in `profile/assets/`. Keep it in
  English and general, with no private details, and keep website links on `nddev.ai`.
- Run `just check` before each commit. Check a presentation change in GitHub's Markdown preview.
- Work on a task branch and merge into `dev` through a pull request. Then move `main` forward to
  the verified `dev` as a fast-forward.
